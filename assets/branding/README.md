| Color | Hex | RGB | Usage |
|-------|-----|-----|-------|
| **Cyan** | `#00B4D8` | 0, 180, 216 | Primary accent, logo gradient start |
| **Teal** | `#2EC4B6` | 46, 196, 182 | Logo gradient middle, backgrounds |
| **Green** | `#38B000` | 56, 176, 0 | Logo gradient end, success states |
| **Dark Slate** | `#3D4F5F` | 61, 79, 95 | "AURA" text on light, dark backgrounds |

| **Near Black** | `#1A1A2E` | 26, 26, 46 | Dark mode backgrounds |

### Gradient Specifications

**Primary Brand Gradient**
- Direction: 135° (top-left to bottom-right)
- Stops: Cyan (#00B4D8) → Teal (#2EC4B6) → Green (#38B000)

## Usage Guidelines

### Do
- Use official logo files without modification
- Maintain minimum clear space equal to the height of the diamond icon
- Use appropriate variant for background color (light logo on dark, dark logo on light)
- Use high-resolution @3x visuals for print and large displays

### Don't
- Stretch, skew, or distort the logo
- Change logo colors outside the brand palette
- Place logo on busy or low-contrast backgrounds
- Recreate or approximate the logo manually
- Use visuals without proper attribution to AuraSense
