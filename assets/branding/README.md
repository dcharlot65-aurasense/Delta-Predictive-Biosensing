# AuraSense Branding Assets

This folder contains official branding assets for AuraSense and the Delta-Predictive Biosensing (DPB) framework.

## Logo Variants

| File | Description | Use Case |
|------|-------------|----------|
| `aurasense-icon.png` | Diamond symbol only | Favicons, app icons, small spaces |
| `aurasense-logo-light.png` | Full logo on light background | Light-themed documents, white backgrounds |
| `aurasense-logo-dark.png` | Full logo on dark background | Dark-themed documents, presentations |

## Brand Colors

| Color | Hex | Usage |
|-------|-----|-------|
| Cyan | `#00B4D8` | Primary accent, logo gradient start |
| Teal | `#2EC4B6` | Logo gradient middle |
| Green | `#38B000` | Logo gradient end |
| Dark Gray | `#3D4F5F` | "AURA" text (light background) |
| White | `#FFFFFF` | "AURA" text (dark background) |

## Usage Guidelines

### Do
- Use official logo files without modification
- Maintain minimum clear space around the logo
- Use appropriate variant for background color

### Don't
- Stretch, skew, or distort the logo
- Change logo colors outside brand palette
- Place logo on busy or low-contrast backgrounds
- Recreate or approximate the logo

## File Formats

- **PNG**: For web, presentations, and documents
- **SVG**: For scalable graphics (if available)
