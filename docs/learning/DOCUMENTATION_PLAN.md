## Book Structure

### Book 1: Foundations - "Listening to the Body"
*How humans learned to measure health*

| Chapter | Title | Key Concepts | Historical Context |
|---------|-------|--------------|-------------------|
| 1.1 | The First Measurements | Pulse, temperature, observation | Ancient medicine (3000 BCE) |
| 1.2 | The Stethoscope Revolution | Sound, amplification, diagnosis | Laennec, 1816 |
| 1.3 | Electricity Meets Medicine | Bioelectricity, signals | Galvani, 1780s |
| 1.4 | The ECG is Born | Heart rhythms, recording | Einthoven, 1903 |
| 1.5 | Reading Brain Waves | EEG, consciousness | Berger, 1924 |
| 1.6 | The Digital Age | Computers, data, algorithms | 1960s-present |
| 1.7 | Where We Are Today | AI, wearables, prediction | 2020s |

**Learning Outcomes**:
- Understand why we measure body signals
- Know the key inventions that made it possible
- See how technology changed medicine
- Get excited about what's next

---

### Book 2: Signals - "The Body's Messages"
*Understanding what your body is saying*

| Chapter | Signal | What It Measures | Common Uses |
|---------|--------|------------------|-------------|
| 2.1 | ECG | Heart's electrical activity | Heart disease, fitness |
| 2.2 | EEG | Brain's electrical activity | Sleep, seizures, focus |
| 2.3 | EMG | Muscle electrical activity | Movement, fatigue |
| 2.4 | PPG | Blood flow (optical) | Heart rate, oxygen |
| 2.5 | EDA | Skin conductance | Stress, emotions |
| 2.6 | Respiration | Breathing patterns | Sleep apnea, relaxation |
| 2.7 | Movement | Accelerometer, gyroscope | Activity, balance, gait |
| 2.8 | Voice | Acoustic features | Mood, neurological health |

**Each Chapter Includes**:
- What the signal looks like (with pictures)
- Where it comes from in the body
- What "normal" looks like
- What "abnormal" might mean
- How to record it yourself
- Fun facts and history

## Writing Guidelines

### Language Rules

1. **Sentence Length**: 15-20 words maximum
2. **Paragraph Length**: 3-5 sentences maximum
3. **Vocabulary**: Define any word a 13-year-old might not know
4. **Voice**: Active voice, present tense when possible
5. **Tone**: Friendly, encouraging, curious

### Explanation Patterns

**For Concepts**:
```
What is it? → Why does it matter? → How does it work? → Example → Try it yourself
```

**For Procedures**:
```
Goal → What you need → Steps (numbered) → What to expect → Troubleshooting
```

**For History**:
```
The problem → The person → The breakthrough → The impact → Connection to today
```

### Analogies to Use

| Technical Concept | Everyday Analogy |
|-------------------|------------------|
| Signal filtering | Tuning a radio to one station |
| Sampling rate | Frames per second in a video |
| Frequency | Musical notes (pitch) |
| Amplitude | Volume of sound |
| Neural network | Team of experts voting |
| Training | Practice makes perfect |
| Noise | Static on old TV |
| Threshold | Finish line in a race |
