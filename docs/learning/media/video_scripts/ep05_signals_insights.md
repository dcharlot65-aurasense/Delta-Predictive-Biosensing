### Production Notes

**Live Demo Technical Requirements:**
- Actual ECG hardware setup (3-lead, medical-grade or research-grade)
- Real-time signal processing software with visualization
- Screen recording software to capture processing steps
- Backup pre-recorded demo in case live fails
- Test thoroughly—ensure clean signal capture in filming environment
- Have backup power (battery) for all demo equipment
- Demo environment must be quiet, free of electrical interference

**Animation Requirements:**
- Signal processing chain visualization (conveyor belt metaphor)
- ECG waveform labeling (P, QRS, T waves)
- Neural network processing visualization (from Ep 4 style)
- Clean, modern dashboard UI designs
- Personalized learning timeline animation
- Privacy-preserving architecture diagram

**B-Roll Needs:**
- **Critical**: Real user testimonial footage (permissions required)
  - AFib detection success story
  - Epilepsy seizure warning user
  - Athlete using HRV for training
- Medical settings: ICU monitoring, doctor-patient consultations
- Wearable technology: Various devices being worn naturally
- Daily life: Exercise, sleep, work, meditation, stress
- Diverse representation: Age, gender, ethnicity, ability
- Product shots: Clean, professional sensor hardware

**Graphics & Data Visualization:**
- ECG waveform: Medically accurate, clearly labeled
- Noise sources: Color-coded, educational
- Filter effects: Before/after comparisons
- Heart rate variability: Time-domain and frequency-domain graphs
- Sleep architecture: Industry-standard hypnogram
- Stress timeline: Intuitive traffic light system
- Personalized dashboard: Aspirational but realistic UI

**Music Palette:**
- Opening story (0:00-0:30): Tense, quiet, intimate piano
- Educational journey (0:30-4:00): Bright, curious, rhythmic
- Applications (4:00-5:30): Inspiring, building momentum
- Future vision (5:30-7:00): Hopeful, expansive, emotional crescendo
- Closing (7:00-8:00): Warm, resolved, empowering

**On-Screen Text Strategy:**
- Opening: "Based on true events" (establish credibility)
- Technical specs: Brief, contextual (e.g., "1 millivolt = 0.001V")
- Real-time metrics: Live HR, HRV during demo
- Application stats: Success rates, use cases
- Privacy messaging: "Your data. Your device."
- Call-to-action: Links, resources, community
- Keep text on screen 1.5x reading time minimum

**Accessibility:**
- Full captions with technical terms defined on first use
- Audio descriptions of all visualizations
- High contrast UI (WCAG AAA compliant)
- Color-blind friendly palette throughout
- Text alternatives for all data graphs
- Closed captions note sound effects (heartbeat, alerts)

**Story Arc & Emotional Journey:**
- 0:00-0:30: **Tension** (Sara's story creates stakes)
- 0:30-2:00: **Curiosity** (How does it work?)
- 2:00-4:00: **Discovery** (Live demo reveals magic)

- 5:30-7:00: **Hope** (Future possibilities)
- 7:00-8:00: **Empowerment** (You can do this)

**Tone & Delivery:**
- Opening: Serious, stakes-raising (Sarah's story is real)
- Technical sections: Clear, confident, not rushed
- Demo: Enthusiastic, real-time reactions
- Applications: Inspiring, human-focused
- Future: Optimistic but grounded
- Closing: Direct, empowering, warm invitation
