# Quick Reference Card 2: What's Normal? ✓⚠️

> **Side-by-side comparisons** - Learn to spot healthy vs. concerning patterns

---

## 1. ECG - Heart Rhythm

### ✓ Normal Sinus Rhythm
```
    R   R   R   R   R
   /\  /\  /\  /\  /\
  /  \/  \/  \/  \/  \
 P    P   P   P   P
_________________________T T T T T

Regular spacing ← → ← → ← →
Heart Rate: 60-100 bpm
```

### ⚠️ Atrial Fibrillation (AFib)
```
  R     R  R    R   R
 /\    /\  /\ /\   /\
/  \  /  \/  V  \ /  \
~~~~~~~~~~~~~~~~~~~~~
Irregular, no clear P waves
Variable R-R spacing
```

### ⚠️ Tachycardia (Too Fast)
```
R R R R R R R R R
/\/\/\/\/\/\/\/\/\
__________________

Heart Rate: >100 bpm
Short R-R intervals
```

**What to Look For:**
- ✓ Regular spacing between beats
- ✓ Clear P-QRS-T pattern
- ⚠️ Missing waves
- ⚠️ Irregular rhythm
- ⚠️ Very fast or very slow

## 2. EEG - Brain Activity

### ✓ Awake & Alert
```
Beta waves (13-30 Hz)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Low amplitude, fast frequency
```

### ✓ Relaxed, Eyes Closed
```
Alpha waves (8-13 Hz)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Moderate amplitude, rhythmic
(strongest at back of head)
```

### ✓ Deep Sleep (Stage 3)
```
Delta waves (0.5-4 Hz)
~~~~~~~~~~~~~~~~~~~~~~~
High amplitude, slow waves
```

### ⚠️ Seizure Activity
```
Spike-and-Wave Pattern
   /\    /\    /\    /\
  /  \  /  \  /  \  /  \
 /    \/    \/    \/    \
_________________________
Very high amplitude
Repetitive sharp spikes
```

**What to Look For:**
- ✓ Wave type matches activity (awake = beta, relaxed = alpha)
- ✓ Symmetric patterns (left/right brain similar)
- ⚠️ Sharp spikes or "spike-wave" patterns
- ⚠️ One side much different than other
- ⚠️ Flat line (no activity)

### ✓ Relaxed Muscle
```

Almost flat, minimal noise
Amplitude: <5 µV
```

### ✓ Normal Contraction
```
  Light      Medium      Strong

Activity increases with effort
```

### ⚠️ Muscle Fatigue
```
Start of Exercise:
||||||||||||||||||||||||
High amplitude, dense spikes

After 2 minutes (Fatigued):
|  |  |  |  |  |  |  |
Lower amplitude, slower firing
```

### ⚠️ Tremor
```
|¯| |¯| |¯| |¯| |¯|
  v   v   v   v   v
Regular 4-6 Hz shaking
(Parkinson's-type tremor)
```

**What to Look For:**
- ✓ Quiet when relaxed
- ✓ Bursts only during movement
- ⚠️ Activity when trying to relax
- ⚠️ Decreasing amplitude over time (fatigue)
- ⚠️ Rhythmic pattern at rest (tremor)

## 4. PPG - Blood Flow & Oxygen

### ✓ Healthy Pulse Wave
```
      Peak
      /\
     /  \_____ Dicrotic Notch
    /         \
___/           \____

SpO2: 95-100%
Strong, regular pulses
```

### ⚠️ Low Blood Oxygen
```
      /\
     /  \        Weak signal
    /    \       Low amplitude
___/      \_____

SpO2: <90%
Medical attention needed
```

### ⚠️ Irregular Pulse (AFib)
```
 /\   /\  /\    /\  /\
/  \_/  \/  \__/  \/  \
________________________
Variable spacing
Variable amplitude
```

### ⚠️ Poor Signal Quality
```
/\/\/\/\  Motion noise
________  Too tight/loose
    /     Slow drift
___/
```

**What to Look For:**
- ✓ Clear, sharp peaks
- ✓ Regular spacing (like a metronome)
- ✓ Visible dicrotic notch
- ⚠️ Irregular timing
- ⚠️ Very weak signal
- ⚠️ No clear peaks

## 5. EDA - Stress Response

### ✓ Calm & Relaxed
```
Baseline
____________/¯¯¯¯¯¯¯¯\____

Low tonic level
Few/no phasic responses
```

### ✓ Normal Stress Response
```
STRESSOR ↓
        /¯¯¯¯¯¯\
    ___/        \____

Single clear peak
Returns to baseline
```

### ⚠️ Chronic Stress
```
________________________
       Elevated
_______________________
Baseline stays high
Doesn't return to normal
```

### ⚠️ Anxiety/Panic
```
    /\/\/\/\/\/\
   /            \
__/              \____
Multiple rapid peaks
Very high amplitude
```

**What to Look For:**
- ✓ Low baseline when calm
- ✓ Clear response to events
- ✓ Returns to baseline after 1-5 min
- ⚠️ High baseline (always elevated)
- ⚠️ Continuous rapid peaks
- ⚠️ Never returns to normal

## 6. HRV - Heart Rate Variability

### ✓ Healthy HRV
```
R-R Intervals:
|←850ms→|←920ms→|←880ms→|←910ms→|

Variation = GOOD!
RMSSD: 40-100 ms
SDNN: 50-100 ms
```

### ⚠️ Low HRV (Stress/Fatigue)
```
R-R Intervals:
|←800ms→|←805ms→|←802ms→|←800ms→|

Too regular = BAD!
RMSSD: <20 ms
SDNN: <30 ms
Sign of stress or overtraining
```

**What to Look For:**
- ✓ Variation between heartbeats (normal!)
- ✓ RMSSD > 40 ms
- ⚠️ Very regular heartbeats (low variation)
- ⚠️ RMSSD < 20 ms

## 🎯 Quick Decision Matrix

| Signal | Metric | Normal ✓ | Check This ⚠️ | Urgent 🚨 |
|--------|--------|----------|---------------|-----------|
| **ECG** | Heart Rate | 60-100 bpm | <60 or >100 | <40 or >150 |
| **ECG** | Rhythm | Regular | Occasional skip | Very irregular |
| **EEG** | Amplitude | 10-100 µV | >200 µV spikes | Seizure pattern |
| **EMG** | At Rest | <5 µV | 5-20 µV | Constant activity |
| **PPG** | SpO2 | 95-100% | 90-94% | <90% |
| **EDA** | Baseline | Low & stable | Elevated | Extreme peaks |
| **HRV** | RMSSD | 40-100 ms | 20-40 ms | <20 ms |

## 📊 Visual Checklist: Is My Signal Good Quality?

### Good Signal ✓
- [ ] Clear, recognizable waveform shape
- [ ] Consistent amplitude
- [ ] Regular rhythm (if expected)
- [ ] Smooth baseline (not drifting)
- [ ] No sudden jumps or dropouts

### Poor Signal ⚠️
- [ ] Can't see expected features
- [ ] Lots of spikes/noise
- [ ] Wandering baseline
- [ ] Flat sections
- [ ] Motion artifacts (sudden jumps)

---

## 💡 Pro Tips

**ECG:** Count 6 seconds of beats, multiply by 10 for quick heart rate
**EEG:** Alpha waves disappear when eyes open (normal!)
**EMG:** Should be almost silent at rest
**PPG:** Cold fingers = weak signal (warm them up!)
**EDA:** Response takes 2-5 seconds (slower than other signals)
**HRV:** Lower is NOT always better - extremely high HRV can also indicate issues

---

**Remember:** When in doubt, compare to a baseline!
Record a few minutes of "normal" data for your subject, then compare any questionable readings to that baseline.
